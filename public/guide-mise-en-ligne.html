Générer l'empreinte scrypt de ton mot de passe Admin

Pour que même quelqu'un qui lit ton code sur GitHub ne connaisse jamais ton mot de passe /admin, on ne stocke que son empreinte cryptographique scrypt dans Vercel.

Préparateur de commande : tape ci-dessous le mot de passe Admin secret que tu veux utiliser :

Copie-colle cette commande dans ton Terminal Mac :

Terminal macOS — Générer le hash scrypt 
cd /Users/gast/Projets/coincheirb
npm run hash:password -- "MonMotDePasseSecretEirb2026!"
Important : Le terminal va t'afficher une ligne qui commence par scrypt$.... Garde-la sous les yeux : tu vas la coller dans Vercel à l'Étape 3 !

4
Base Temps Réel Multi-Téléphones (Recommandé pour 40-100 joueurs)

Connecter Supabase Gratuit en 3 minutes

Pour que les 40 à 100 téléphones de la soirée et le vidéoprojecteur /live partagent une base PostgreSQL persistante :

  1. Crée un projet gratuit sur 👉 https://supabase.com/dashboard.
  2. Ouvre SQL Editor > New query et exécute dans l'ordre les 3 fichiers SQL situés dans ton dossier supabase/migrations/ :
    • supabase/migrations/0001_initial_schema_and_rls.sql
    • supabase/migrations/202611250002_tournament_live_state.sql
    • supabase/migrations/202611250003_club_accounts_and_table_locks.sql
  3. Dans Supabase (Project Settings > API), copie tes 3 clés et ajoute-les dans Vercel > Settings > Environment Variables :
    • NEXT_PUBLIC_SUPABASE_URL
    • NEXT_PUBLIC_SUPABASE_ANON_KEY
    • SUPABASE_SERVICE_ROLE_KEY
  4. Clique sur Redeploy dans Vercel.
